## 📝 文档维护指南

### 添加新文档

1. 在本文档的「文档清单」中添加条目
2. 在「文档地图」中标注位置
3. 如有必要，在「常见任务速查」中添加索引

### 更新文档

- **AGENTS.md** - 项目结构变更时更新
- **HANDOVER.md** - 完成/新增任务时更新
- **CHANGELOG.md** - 每次发布新版本时更新
- **ARCHITECTURE.md** - 架构重大变更时更新

### 文档命名规范

- 大写文件名（如 `README.md`）
- 使用连字符分隔单词（如 `SPARKLE_SETUP.md`）
- 英文优先，必要时添加中文注释
