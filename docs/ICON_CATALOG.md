# Agent Island 主图标分类与状态说明

## 图标分类体系

### 六大图标

| 图标 | 名称 | 分类 | 性格 | 适合场景 |
|------|------|------|------|----------|
| 🐕 | Dog | 动物 | 忠诚、活泼 | 默认选择，通用场景 |
| 🐱 | Cat | 动物 | 独立、优雅 | 喜欢安静、专注的场景 |
| 🤖 | Robot | 科技 | 理性、高效 | 编程、自动化任务 |
| 🏝️ | Island | 自然 | 放松、度假 | 创意工作、写作 |
| 👻 | Ghost | 幻想 | 神秘、趣味 | 夜晚工作、实验性项目 |
| 🗼 | Lighthouse | 建筑 | 指引、守护 | 长期项目、监督模式 |

## 状态表现详表

### 🐕 Dog（柯基犬）

**设计理念**：全身像，向右奔跑，像素级可爱

| 状态 | 视觉表现 | 动画细节 |
|------|----------|----------|
| **Idle** | 侧躺休息姿势 | 静止，100% 不透明 |
| **Sleeping** | 同上，呼吸起伏 | 缩放 0.92x，透明度 0.85，2秒周期 |
| **Running** | 四肢奔跑动画 | 4帧循环，尾巴摇摆，12fps |
| **Waiting** | 警觉站立 | 缩放脉冲 0.88x，0.6秒周期，提醒感 |

**像素规格**：16×16 网格，橙白配色

```

    █████
    █████  
     ███  ← 头
   ████████
  ██  ██  ██ ← 身体
    ██ ██   ← 腿
     ██     ← 尾巴
```

### 🐱 Cat（橘猫头像）

**设计理念**：正面头像，大耳朵，表情丰富

| 状态 | 视觉表现 | 动画细节 |
|------|----------|----------|
| **Idle** | 正常睁眼，耳朵平放 | 偶尔眨眼 |
| **Sleeping** | 闭眼睡觉，耳朵下垂 | 缓慢呼吸，耳朵轻微摆动 |
| **Running** | 睁眼，尾巴摇摆 | 耳朵快速抖动，模拟警觉 |
| **Waiting** | 睁眼，**耳朵竖起** | 耳朵抬高1像素，进入警觉模式 |

**特色**：耳朵状态是 Cat 图标的核心表达

```

  ██  ██            ███ ███
 ████ ████         █████ ████
```

### 🤖 Robot（复古机器人）

**设计理念**：方头方身，天线闪烁，机械感

| 状态 | 视觉表现 | 动画细节 |
|------|----------|----------|
| **Idle** | 天线暗，眼睛常亮 | 静止 |
| **Sleeping** | 天线微光，眼睛半闭 | 全身轻微上下浮动（悬浮感） |
| **Running** | 天线快速闪烁 | 身体左右摇摆，模拟行走 |
| **Waiting** | 天线红灯闪烁 | 眼睛闪烁警报，身体轻微震动 |

**特色**：天线是状态指示器，闪烁频率代表忙碌程度

---

### 🏝️ Island（热带岛屿）

**设计理念**：小岛+棕榈树，海浪环绕，度假感

| 状态 | 视觉表现 | 动画细节 |
|------|----------|----------|
| **Idle** | 平静海面 | 静止 |
| **Sleeping** | 日落色调 | 海浪缓慢起伏，整体变暗 |
| **Running** | 活跃海浪 | 棕榈树叶摇摆，海浪拍打 |
| **Waiting** | 船只进港信号 | 灯塔光束旋转（如果有），树叶快速摇摆 |

**特色**：海浪动画是状态的核心表达

---

### 👻 Ghost（可爱幽灵）

**设计理念**：圆润幽灵，漂浮效果，俏皮表情

| 状态 | 视觉表现 | 动画细节 |
|------|----------|----------|
| **Idle** | 正常漂浮 | 轻微上下浮动 |
| **Sleeping** | 闭眼，变小 | 下沉到底部，透明度降低 |
| **Running** | 快速穿梭 | 左右摇摆，拖尾效果 |
| **Waiting** | 惊讶表情 | 身体膨胀收缩，"!" 表情 |

**特色**：Sleeping 时像幽灵"熄火"，Running 时像鬼魂穿梭

---

### 🗼 Lighthouse（灯塔）

**设计理念**：海边灯塔，光束指引，守护感

| 状态 | 视觉表现 | 动画细节 |
|------|----------|----------|
| **Idle** | 光束静止 | 静止 |
| **Sleeping** | 夜间模式 | 光束变暗，缓慢旋转 |
| **Running** | 白昼模式 | 光束快速旋转，海鸥飞过 |
| **Waiting** | 紧急模式 | 红光闪烁，光束快速扫射 |

**特色**：光束旋转速度 = 忙碌程度

## 动画参数统一规范

所有主图标遵循相同的动画参数：

```swift
// 动画周期
let breatheDuration: Double = 2.0   // Sleeping - 缓慢
let pulseDuration: Double = 0.6     // Waiting - 快速
let runFrameRate: Double = 0.12     // Running - 12fps

// 缩放范围
let breatheScale: CGFloat = 0.92    // Sleeping
let pulseScale: CGFloat = 0.88      // Waiting

// 透明度范围
let breatheOpacity: Double = 0.85   // Sleeping
let pulseOpacity: Double = 1.0      // Waiting (不透明)
```

## 扩展建议

### 新增图标 checklist

1. **像素设计**：16×16 网格，4种状态像素画
2. **动画实现**：
   - [ ] Idle 静态帧
   - [ ] Sleeping 呼吸/缩放动画
   - [ ] Running 多帧循环动画
   - [ ] Waiting 脉冲/提醒动画
3. **颜色定义**：状态对应的颜色变化
4. **注册到 IdleIconStyle**：添加到枚举和 iconView
5. **测试预览**：在 `#Preview` 中测试4种状态

### 图标设计原则

1. **状态可读性**：一眼能区分4种状态
2. **动画区分度**：Running 和 Waiting 动画差异明显
3. **像素风格统一**：16×16 网格，保持像素感
4. **颜色协调**：与 StatusPixelIcon 的颜色语义一致
